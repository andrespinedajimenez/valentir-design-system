# Icons

Material Icons SVGs copied from the site, 24×24 viewBox, single `green-900` ink (#1b4332). Used via `<img>` they don't inherit color: on dark backgrounds apply `filter: brightness(0) invert(1)` or change the `fill` in your copy to `ink-inverse`.

- Utilities (Filled): `arrow-forward` (after action links, 16px), `chevron-down` (menus, 18px), `language` (language switcher), `format-quote` (testimonials, in `teal-600`).
- Industries (Outlined, 20px inside the `green-50` tile): `local-shipping-outlined` (Haulers), `construction-outlined` (Trades), `ac-unit-outlined` (Reefer & Cold Chain), `rv-hookup-outlined` (RV & Camper Rental).
- Social: `linkedin`, `facebook`, `instagram` (white, 20px, in a 40px round button).

For new icons use the same set: Google Material Icons, Outlined for concepts and Filled for utilities.
