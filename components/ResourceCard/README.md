# ResourceCard

“Resources” card: no image, the guide title, a 2–3 line summary and a “Read the guide: <title>” link.

**What the consumer provides:** the guide title in *Title Case*, a summary using the benefit — qualifier pattern, and the link (its text repeats the title so it makes sense out of context).

- Below the grid, a shortcut row: one `vg-btn--primary` (Calculate your ROI) followed by `vg-btn--soft` buttons.
- Don't: dates, authors or category tags (the site doesn't use them).
