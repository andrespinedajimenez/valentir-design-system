# IndustryCard

“Solutions by industry” card: a 44px `green-50` icon tile with `radius-lg`, a `card-title-tight` title, a description and “Explore solution →”.

**What the consumer provides:** an *Outlined* Material icon for the segment (**Icons** group: local-shipping, construction, ac-unit, rv-hookup), the segment name and one sentence using the benefit — qualifier pattern.

- Padding `space-xl space-xl space-2xl`; `space-lg` gap between icon and text.
- Incomplete rows are centered (the site centers the fourth card).
- Don't: filled or multicolor icons, illustrations, more than one sentence.
