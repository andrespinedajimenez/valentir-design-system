# Logo

The four official SVG lockups: horizontal and stacked-with-tagline, in color for light backgrounds and in negative for dark ones.

**What the consumer provides:** only the container and the height; use the file as-is in an `<img>` with `alt` “Valentir Green Tech”.

| File | Background | Use |
|---|---|---|
| `valentir-logo-horizontal.svg` | `surface`, `surface-page` | Header, documents, email signatures, decks. Default lockup. |
| `valentir-logo-horizontal-white.svg` | `surface-inverse`, `green-900`, photo with `scrim` | Footer, dark bands, video. |
| `valentir-logo-stacked-tagline.svg` | light | Covers, roll-ups, vertical or square formats. |
| `valentir-logo-stacked-tagline-white.svg` | dark | The same on dark backgrounds. |

- Minimum height: 24px for the horizontal lockup on screen, 120px for the stacked one with tagline (below that the tagline is unreadable: use the horizontal).
- With less than 32px of height available, use the `valentir-mark.webp` mark alone.
- Clear space: the height of the orange dot on every side.
- Don't: recolor, stretch, add shadows or outlines, or place the color version on dark backgrounds or unscrimmed photos.
