# NewsletterPanel

Dark signup panel with a 3px `teal-600` top rule, a `panel-title` title, a description and an inline form (Name, Email, Subscribe).

**What the consumer provides:** the title, one sentence saying what the reader will get, and the submit handler; fields are required and their labels carry an asterisk.

- `vg-field` inputs: 56px tall, `surface` fill, `outline` border, `radius-md`.
- This panel’s button is the only use of `rust-700` on the page.
- On mobile the fields stack full width.
