# Testimonial

Full-width social-proof band on `surface-inverse`: a `teal-600` `format-quote` mark, the quote in `quote`, author, role and one line of verifiable context.

**What the consumer provides:** a real, customer-approved quote (never invented), name and role, and one context sentence with checkable facts (fleet size, time in use).

- Max text width 720px; padding 40px 32px.
- Don't: headshots, star ratings, multiple quotes in a carousel.
